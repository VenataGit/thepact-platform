# Файлове, които живеят на VPS-а (копия в git)

| Файл тук | На сървъра | Какво прави |
|---|---|---|
| `deploy.sh` | `/opt/thepact-platform/scripts/deploy.sh` (cron всяка минута) | Нова версия в `main` → тестовете минават в отделно копие (`git worktree`) → чак тогава fast-forward + `pm2 restart`. При провал на живо остава старата версия и идва сигнал в чата „Сигнал за неработеща система" (веднъж за версия). |
| `logrotate-thepact` | `/etc/logrotate.d/thepact` | Ротация на deploy лога (седмично, 8) и PM2 логовете (дневно / 50 MB, 14). |

Смяна: редактирай тук, push, после копирай на сървъра (`scp` + `bash -n` за проверка). Старият deploy скрипт е запазен в `/root/deploy.sh.before-20261104`.

Капани:
- `npm install` (с dev зависимостите) — без `--production`, иначе jest изчезва и тестовете в deploy-а падат.
- Тестовете вървят с `NODE_ENV=test` и без `.env` (базата е мокната) — никога не пипат прода.
- Ако една версия падне на тестовете, следващият push (с поправката) минава автоматично.
